# Personal Portfolio Website

## Files
- index.html — website structure/content
- style.css — complete responsive UI design
- script.js — navigation, scroll effects, reveal animation and demo contact form

## How to use
1. Open `index.html` in a browser.
2. Replace `Your Name`, `YN`, university/school information and contact links.
3. Replace the profile placeholder with your photo if desired.
4. Replace GitHub/LinkedIn/Resume `#` links with your real URLs.
5. Add completed projects as you build them.

## Important
The contact form is front-end only. To receive real messages, connect it to a backend or a form service later.
